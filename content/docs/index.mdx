SimplyCPF API v2.0.0 exposes source-backed CPF contribution calculations, official reference datasets, and assumption-labelled projections. Every policy-backed response includes provenance and an `official | assumed` status. SimplyCPF is independent and is not affiliated with CPF Board or any government agency.

## Base URL

```text
https://simplycpf.com/api/cpf
```

No authentication is required. Production endpoints are rate limited to 10 requests per 10 seconds per client IP.

## Quick example

```bash
curl -X POST https://simplycpf.com/api/cpf/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "contributionMonth": "2026-08",
    "ordinaryWages": 5000,
    "citizenship": "citizen",
    "birthMonth": "1996-04"
  }'
```

The calculation resolves the effective monthly schedule, CPF wage band, age transition, OW ceiling, official rounding order, account allocation, and post-55 RA routing. Additional Wages require annual OW and prior-AW context; the API returns `422` instead of guessing.

## API categories

- **[Calculation](/developer/api/calculation)** — month-aware contributions, batch processing, and monthly-ledger projections
- **[Age groups](/developer/api/age-groups)** — inclusive upper bounds, age-dependent generic routing, and explicit RA for exact post-closure lookups
- **[Policy reference](/developer/api/policy)** — sourced ceilings, BHS, and retirement sums without silent extrapolation
- **[Interest rates](/developer/api/interest-rates)** — official quarterly declarations and published peg methodology
- **[Investment](/developer/api/investment)** — caller-supplied comparison assumptions, not CPF Board forecasts

## Correctness contract

- Official contribution schedules are supported from January 2023 through December 2027.
- Public reference endpoints return `404` for unsupported policy years; they do not clamp or fabricate values.
- Projection rows after the last publication freeze that policy and mark it `assumed`.
- CPF LIFE output is CPF Board's exact 2026 Standard Plan reference table. SimplyCPF does not calculate personalised payouts; deprecated `cpfLifeEstimate` is `null`.
- Policy responses use 24-hour edge caching with stale revalidation and are not marked immutable.

Read the [machine-readable CPF policy reference](/cpf-rates.md) for first-party sources and per-dataset verification metadata.

---
title: Interest Rates
description: Official quarterly CPF declarations and published methodologies
---

SimplyCPF exposes CPF Board's quarterly declarations. API v2 removes the unsourced monthly SGS series and does not reconstruct a trend from invented observations.

## GET `/interest-rates`

Returns every official quarterly observation currently loaded in the catalogue. The response metadata identifies the latest published quarter, effective coverage, verification date and first-party sources. Each row contains:

```typescript
interface QuarterlyInterestDeclaration {
  quarter: string;
  effectiveFrom: string;
  effectiveTo: string;
  oa: number;
  sa: number;
  ma: number;
  ra: number;
  sourceUrl: string;
  status: "official";
  verifiedAt: string;
}
```

SA, MA, and RA are separate fields because their declared rates were not identical in every historical quarter.

The response envelope is `{ quarterlyRates, methodology, metadata }`. `metadata` is the full `PolicyMetadata` record for the interest dataset plus `latestPublishedQuarter`.

The methodology block records the policy inputs instead of requiring callers to duplicate them:

- OA: the three-month average of major local banks' interest rates, the applicable floor, and the review frequency.
- SMRA: the 12-month average yield of 10-year Singapore Government Securities, the percentage-point markup, applicable floor, floor-guarantee end date, and review frequency.

Source: [CPF Board — How are CPF interest rates determined?](https://www.cpf.gov.sg/service/article/how-are-cpf-interest-rates-determined).

## GET `/interest-rates/smra`

Apply the published SMRA peg to a caller-supplied 12-month average 10YSGS yield:

```bash
curl "https://simplycpf.com/api/cpf/interest-rates/smra?averageSgsYield=3.1"
```

```typescript
interface SmraRateResponse {
  averageSgsYield: number;
  peggedRate: number;
  floorApplied: boolean;
  actualRate: number;
  methodology: string;
  policy: {
    status: "official";
    verifiedAt: string;
    sourceUrls: string[];
  };
  warnings: string[];
}
```

`sgsYield` remains a deprecated alias for one compatibility cycle and produces a warning. It means the 12-month average input, not a single monthly observation.

Successful responses include catalogue-derived methodology provenance under `policy`. A missing or negative average is semantically invalid and returns `422`.

## GET `/interest-rates/trend`

Returns `{ observations, methodology, policy }`. `observations` contains the same official quarters in chronological order, normalised to `oaRate`, `saRate`, `maRate`, and `raRate`; `policy` supplies the per-dataset source and verification metadata. This is a declaration timeline, not a synthetic SGS-yield series.

Policy responses use 24-hour edge caching with stale revalidation and are not immutable.

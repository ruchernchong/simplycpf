---
title: Interest Rates
description: Official quarterly CPF declarations and published methodologies
---

SimplyCPF exposes CPF Board's quarterly declarations. API v2 removes the unsourced monthly SGS series and does not reconstruct a trend from invented observations.

## GET `/interest-rates`

Returns official quarterly observations through 2026 Q3. Each row contains:

```typescript
interface QuarterlyInterestObservation {
  quarter: string;
  effectiveFrom: string;
  effectiveTo: string;
  oaRate: number;
  saRate: number;
  maRate: number;
  raRate: number;
  sourceUrl: string;
  status: "official";
  verifiedAt: string;
}
```

SA, MA, and RA are separate fields because their declared rates were not identical in every historical quarter.

The response also includes CPF Board's methodology:

- OA: three-month average of major local banks' interest rates, subject to the 2.5% legislated floor.
- SMRA: 12-month average yield of 10-year Singapore Government Securities plus one percentage point, subject to the current 4% floor through 2026.

Source: [CPF Board — How are CPF interest rates determined?](https://www.cpf.gov.sg/service/article/how-are-cpf-interest-rates-determined).

## GET `/interest-rates/smra`

Apply the published SMRA peg to a caller-supplied 12-month average 10YSGS yield:

```bash
curl "https://simplycpf.com/api/cpf/interest-rates/smra?averageSgsYield=3.1"
```

```json
{
  "averageSgsYield": 3.1,
  "peggedRate": 4.1,
  "floorApplied": false,
  "actualRate": 4.1,
  "warnings": []
}
```

`sgsYield` remains a deprecated alias for one compatibility cycle and produces a warning. It means the 12-month average input, not a single monthly observation.

## GET `/interest-rates/trend`

Returns the official quarterly observations in chronological order. This is a declaration timeline, not a synthetic SGS-yield series.

Policy responses use 24-hour edge caching with stale revalidation and are not immutable.

title: API Reference
description: SimplyCPF API v2.0.0 endpoint index
---

All endpoints are served below `https://simplycpf.com/api/cpf`. Policy responses include per-dataset provenance and use 24-hour edge caching with stale revalidation.

## Calculation

| Method | Endpoint | Description |
|---|---|---|
| POST | `/calculate` | Month-aware CPF contribution calculation |
| POST | `/calculate/batch` | Up to 100 v2 contribution scenarios |
| POST | `/projection` | Monthly CPF ledger with assumption-labelled annual rows |

## Age groups

| Method | Endpoint | Description |
|---|---|---|
| GET | `/age-groups` | Official bands with inclusive bounds and explicit age-dependent routing |
| GET | `/age-group/find` | Exact month-aware band and fixed SA/RA destination |
| GET | `/age/from-birthdate` | Resolve age and CPF transition context for two months |

## Official policy reference

| Method | Endpoint | Description |
|---|---|---|
| GET | `/ceiling` | Official OW/AW ceiling for a supported month |
| GET | `/ceiling/timeline` | Published ceiling schedules only |
| GET | `/bhs` | Published BHS observations in the policy catalogue |
| GET | `/retirement-sums` | Published BRS/FRS/ERS observations in the policy catalogue |

Unsupported public reference years return `404`; values are never extrapolated. Use each response's effective range, `verifiedAt` date and first-party source links instead of copying a year range into an integration.

## Interest rates

| Method | Endpoint | Description |
|---|---|---|
| GET | `/interest-rates` | Official quarterly CPF declarations and methodology |
| GET | `/interest-rates/smra` | Apply the 12-month-average 10YSGS peg |
| GET | `/interest-rates/trend` | Official quarterly observations; no synthetic SGS series |

## Assumption-based modelling

| Method | Endpoint | Description |
|---|---|---|
| POST | `/investment-comparison` | Compare editable caller-supplied returns |

Non-CPF investment rates are user assumptions, not CPF Board facts or market forecasts.

---
title: Policy Reference
description: Official CPF reference values with per-dataset provenance
---

Public policy endpoints return only values published by CPF Board. They do not silently clamp an unsupported year to the nearest known value and do not extrapolate future amounts.

| Endpoint | Published values | Unsupported request |
|---|---|---|
| `/ceiling` | Sourced contribution-month schedules | `404` |
| `/bhs?year=YYYY` | Sourced BHS cohorts/years | `404` |
| `/retirement-sums?year=YYYY` | Sourced BRS, FRS, and ERS years | `404` |

Omit `year` from the BHS or retirement-sums endpoint to receive all published observations and the latest published value. This collection response is also the canonical supported-year list. A year-specific response carries `status: "official"` and `metadata`; the collection carries the same dataset metadata once at the envelope level.

Each response carries `PolicyMetadata`, including `status`, effective dates, verification date, and first-party sources. Public values are `official`.

Projections use different semantics: when a later BHS or retirement sum has not been published, the last published amount is frozen and each affected projection row is marked `assumed`, with its base year and a warning.

Sources:

- [CPF Board — Basic Healthcare Sum](https://www.cpf.gov.sg/service/article/what-is-the-basic-healthcare-sum)
- [CPF Board — CPF retirement sums](https://www.cpf.gov.sg/member/infohub/educational-resources/what-is-the-cpf-retirement-sum)
- [CPF Board — Ordinary Wage ceiling](https://www.cpf.gov.sg/service/article/what-is-the-ordinary-wage-ow-ceiling)

Policy responses are cached at the edge for 24 hours with stale revalidation. They are not marked immutable.

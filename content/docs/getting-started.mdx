## Contribution request

New clients send the contribution month, Ordinary Wages, citizenship, and either completed age or birth month. Birth month is preferred because CPF's next age rate applies only from the month after the relevant birthday.

```typescript
const response = await fetch("https://simplycpf.com/api/cpf/calculate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    contributionMonth: "2026-08",
    ordinaryWages: 5000,
    citizenship: "citizen",
    birthMonth: "1996-04",
  }),
});

if (!response.ok) {
  throw new Error((await response.json()).error);
}

const result = await response.json();
console.log(result.contribution, result.schedule, result.policy);
```

The response retains `contribution`, `distribution`, and `afterCpfContribution`, and adds the applicable wage band, effective schedule, RA routing branches, warnings, and dataset provenance.

## Additional Wages

CPF's annual AW ceiling depends on annual OW already subject to CPF and AW already subject to CPF. Supply both values whenever `additionalWages` is positive:

```json
{
  "contributionMonth": "2026-12",
  "ordinaryWages": 8000,
  "additionalWages": 20000,
  "additionalWageCeilingContext": {
    "annualOrdinaryWagesSubjectToCpf": 96000,
    "priorAdditionalWagesSubjectToCpf": 0
  },
  "citizenship": "citizen",
  "age": 40
}
```

Omitting that context returns HTTP `422`; the service does not infer annual wages.

## Projection request

```json
{
  "monthlyIncome": 6000,
  "birthDate": "04/1990",
  "startMonth": "2026-08",
  "initialBalances": {
    "oa": 90000,
    "sa": 70000,
    "ma": 50000,
    "ra": 0
  },
  "initialYearToDateAccruedInterest": {
    "oa": 0,
    "sa": 0,
    "ma": 0,
    "ra": 0
  },
  "initialCashTopUpTaxReliefUsedThisYear": 0,
  "endAge": 65,
  "citizenship": "citizen"
}
```

`initialBalances` are the opening balances of `startMonth`. For a start after January, supply accrued-but-uncredited interest from CPF records and cash top-up relief already used in that calendar year. The projection ledger is monthly. It holds fixed monthly OW and the last published future policy constant unless the caller supplies different context, and labels affected rows `assumed`. The `retirementTransfer` field routes OA to SA below 55 and RA from 55.

## Errors

| Status | Meaning |
|---|---|
| `400` | Malformed syntax or primitive value |
| `404` | No sourced official policy for the requested public reference month/year |
| `422` | Well-formed request lacks required context, such as AW ceiling context |
| `429` | Rate limit exceeded |

Deprecated for one compatibility cycle: contribution `income` → `ordinaryWages`, `date` → `contributionMonth`; projection `income`/`age`/`years` → the v2 monthly-ledger fields, `startAge` → exact `birthDate`, and `oaToSaTransfer` → `retirementTransfer`; age utility `birthDate` → `birthMonth` plus `contributionMonth`; interest `sgsYield` → `averageSgsYield`. Deprecation warnings are returned in successful responses.
